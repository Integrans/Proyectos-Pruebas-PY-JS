# Proyectos de Pruebas Técnicas en Python y JavaScript

Este repositorio contiene proyectos diseñados para evaluar habilidades profesionales como:

- ✅ Código limpio
- ✅ Programación orientada a objetos (POO)
- ✅ Programación funcional
- ✅ Patrones de diseño
- ✅ Testing y arquitectura

Cada carpeta contiene:
- Enunciado detallado (`enunciado.md`)
- Estructura inicial sugerida (`estructura-sugerida/`)
- Criterios de evaluación
- Extras opcionales para escalar dificultad
