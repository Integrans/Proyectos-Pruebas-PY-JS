
## Enunciado: Administrador de Tareas (Node.js + Frontend)

Construye una aplicación fullstack que permita crear, editar, completar y eliminar tareas. Incluye autenticación, API REST y una interfaz web simple.

### Requisitos:
- Backend con Node.js (Express)
- Frontend simple (puede ser HTML/CSS o React)
- CRUD de tareas
- Login con JWT
- Código limpio y modular
